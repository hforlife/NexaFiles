# UX des lecteurs

Comic et PDF restent centrés sur le contenu, avec contrôles masquables, compteur et navigation rapide. La recherche PDF et les signets restent visibles dans l'AppBar.

EPUB expose directement Sommaire, Recherche, Signet et Aa. Texte/Markdown conserve une interface légère. Le lecteur image affiche l'index dans la séquence, le swipe, le zoom et le double tap.

Les préférences de lecture sont accessibles depuis Paramètres sans ajouter un écran surchargé.
